# Rodinné cesty

Interaktivní rodinná cestovní kronika — světová mapa, měsíční časová osa a připravované napojení na Plánovač a Supabase.

**Stav:** Rozpracovaný projekt, zatím bez produkčních dat. Vývoj probíhá v samostatné větvi.

**Soukromí:** Tento repozitář je veřejný. Osobní cestovní záznamy, fotky pasů, citlivé údaje a tajné klíče sem nepatří.

První demo, dokumentace a databázový návrh budou ve vývojové větvi. Do produkční Supabase se zatím nezasahuje.
